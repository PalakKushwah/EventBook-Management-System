# EventBook-Management-System

## 📌 Project Overview
EventBook Management System is a MERN Stack based web application developed for managing online events and ticket bookings.

The system allows users to:
- Register and Login
- Browse Events
- View Event Details
- Book Tickets
- Manage Bookings

Admins and Organizers can:
- Create Events
- Update Events
- Delete Events
- Monitor Bookings

## 🛠️ Installation Steps

### Clone Repository
```bash
git clone https://github.com/PalakKushwah/EventBook-Management-System.git
```

### Backend Setup
```bash
cd backend
npm install
npm start
```

### Frontend Setup
```bash
cd frontend
npm install
npm start
```
