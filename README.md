# EventHub - Event Management System

EventHub is a **full-stack event management system** with an admin panel, organizer panel, and attendee panel.  
It allows creating, managing, and registering for events with authentication and role-based access control.

---

## Tech Stack
- **Backend:** Node.js, Express.js, MongoDB
- **Frontend:** React.js (separate apps for Admin, Organizer, Attendee)
- **Authentication:** JWT (Admin / Organizer / Attendee roles)
- **Email Service:** Nodemailer (SMTP - Gmail)
- **Security:** reCAPTCHA v2
- **Deployment:** Node (production mode)
